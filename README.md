## Overview

This repository contains an R-based interface and examples for using a New York Times Web API to retrieve JSON data and transform it into an R data.frame (tibble). The assignment was to sign up for an API key at https://developer.nytimes.com/apis, choose one NYT API, fetch JSON responses, and convert them into tidy R data structures.

The README explains how to set up your API key, install required packages, run the example code, and adapt the workflow to other NYT APIs (e.g., Article Search API, Top Stories API, Most Popular API).

## What I did

- Added documentation and usage examples showing how to call a NYT API from R.
- Included example R code to request JSON from the NYT Article Search endpoint, parse it with jsonlite, and convert it into a tibble with useful fields.
- Added notes about storing your API key securely, paging through results, and rate limits.
